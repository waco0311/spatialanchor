# Spatial Anchor（空間アンカー）

Create Aeronautics（Simulated）の飛行船を、起動した瞬間の座標に**完全固定**するアドオン Mod です。

---

## 概要

応力（回転）を供給すると、飛行船をその場にガッチリ固定します。位置だけでなく**角度も固定**されるため、風や慣性で流されることなく、空中の定位置に船を留めておけます。

宇宙戦艦的な「その場停泊」「空中要塞の固定」などに使えます。

---

## 動作要件

### 対応バージョン
- **Minecraft 1.21.1**
- **NeoForge**

### 前提 Mod（すべて必須）
| Mod | バージョン |
|-----|-----------|
| Create | 6.0.10-280 以降 |
| Sable | 2.0.3 以降 |
| Create Aeronautics (Simulated) | 1.2.1 以降 |

> Flywheel など Create の前提 Mod も併せて必要です。

---

## マルチプレイでの導入

### サーバー・クライアント共通
1. 上記の前提 Mod をすべて導入する
2. `spatialanchor-x.x.x.jar` を `mods/` フォルダに入れる

### 重要な注意点
- **サーバーと全クライアントで Mod 構成・バージョンを完全に一致させてください。** バージョンが異なると接続できません。
- このアンカーの設定はサーバー側で管理されます（`config/spatialanchor-server.toml`）。クライアント側の設定変更は不要です。

---

## 使い方

1. **クラフト**：メカニカルクラフターで作成（破砕ホイールと同じ 5×5 配置）
2. **設置**：組み立て済みの飛行船にアンカーブロックを設置
3. **起動**：アンカーに回転を供給する
   - **64 RPM 以上**の回転が必要
   - 船の重さに応じた**応力（Su）**が必要
4. 起動すると船がその場に完全固定される
5. **解除**：回転を止めるか、応力が不足すると自動的に解除される

### 状態確認
- アンカーを**右クリック**：稼働状況・固定座標・船重量・必要応力を表示
- アイテムを持って **Shift 長押し**：詳細説明を表示

---

## 必要応力について

必要応力は**船の重さに比例**します。重い船ほど大きな応力が必要です。

- クリエイティブモーターなど高出力の応力源なら、重い船でも 64 RPM で固定可能
- 水車だけなど貧弱な応力源では、重い船は「応力不足」で起動しません
- 回転速度（64〜256 RPM）を上げても消費応力は変わりません

---

## 設定（config/spatialanchor-server.toml）

| 項目 | 説明 | 既定値 |
|------|------|--------|
| `weightMultiplier` | 必要応力の倍率 | 1.0 |
| `stressPerWeightUnit` | 重量1単位あたりの応力 | 4.0 |
| `minSpeed` | 起動に必要な最低回転速度 | 64 |
| `maxSpeed` | 応力消費が頭打ちになる速度 | 256 |

例：`weightMultiplier = 2.0` にすると、必要応力が2倍になり難易度が上がります。
